# PhishGuard AI

PhishGuard AI is an advanced, AI-based Phishing URL Detection System. It allows users to submit URLs and instantly receive a risk assessment powered by a Machine Learning model. The system features a modern, bilingual (Arabic/English) interface, a transparent explanation system, and a strictly managed public history.

## Quick Start
1. **Frontend:** cd frontend -> 
pm install -> 
pm run dev
2. **Backend:** cd backend -> pip install -r requirements.txt -> uvicorn api_server:app --reload
3. **Database:** Execute supabase/schema.sql in your Supabase SQL Editor.
